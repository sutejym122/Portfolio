# Developer Portfolio

A personal developer portfolio built with React, Three.js, Vite, and Tailwind CSS to showcase my software engineering work, projects, experience, and technical background.

The portfolio is designed as a visual landing page for recruiters, engineers, and hiring teams to quickly understand the kind of systems and products I build.

## Why This Exists

My GitHub and resume include work across cloud-native systems, observability platforms, automation tools, mobile apps, and AI-assisted workflows. This portfolio brings those projects together in one place with a cleaner visual presentation.

## Repository Structure

- `src/` - main application source code
- `public/` - static assets
- `index.html` - app entry HTML file
- `vite.config.js` - Vite configuration
- `tailwind.config.cjs` - Tailwind CSS configuration

## Running Locally

Clone the repository:

```bash
git clone https://github.com/sutejym122/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
